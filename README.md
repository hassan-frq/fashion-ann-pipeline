# fashion-ann-pipeline

End-to-end, reproducible ML pipeline that trains a fully-connected
Artificial Neural Network (ANN) on Fashion-MNIST, versioned with Git
(code) and DVC (data/model artifacts) using Google Drive as the DVC
remote.

## Problem

Classify a 28x28 grayscale Fashion-MNIST image into one of 10 clothing
categories using a dense ANN (no convolutions). Target: >= 85% test
accuracy.
